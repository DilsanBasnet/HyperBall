# Hyper Ball  - 2D Arcade Game [![Hackatime](https://img.shields.io/badge/Hackatime-19h_33m-ff477e?logo=wakatime&logoColor=white)](https://github.com/DilsanBasnet)

## DEMO:   [HyperBall](https://dilsanbasnet.itch.io/hyperball)

It is a modern 2D arcade game build using C # language and Unity Game Engine. It is a like replica of classic blockbrick 2d arcade game  where player have to breake the blocks having different levels  to score points but having many more features then the old classic game such as : modern cool background,  modern UI , & custom feature sets Ball Skin Section Features , paddle skin features to change the paddle skins, Exit, Main Menu Buttons etc.. 

## Controls : 
- A to Move Paddle Left
- D to Move Paddle Right
- ESC key to Pause & Again ESC Key to Resume 

## Build With : 

- Unity - Game Engine
- C# - as Language.
- Pixlr - for Button Designing, Name Designing and other designing stuffs...
- Pinterest - Some Sprites like bg, some buttons, and other necessary stuffs..
